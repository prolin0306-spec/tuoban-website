# 家长作业查询函数

此函数只接受 `summary` 查询，不提供写入接口。老师在作业学生管理中输入准确的家长手机号并逐人核对后，才能关联学生。函数按家长每日反馈的 `children._id` 和手机号核验，只读取老师明确关联的 `hw_students.feedbackChildId` 对应作业；未关联或重复关联都不会自动按姓名或班级名称匹配。

部署时使用根目录 `cloudbaserc.webParentHomework.json`。函数必须与每日反馈所用 CloudBase 环境一致，并设置 `WEB_PARENT_HOMEWORK_ENV_ID`。上线还需同时部署含关联操作的 `webHomework` 和静态页面。部署前核对家长匿名登录可调用函数以及所需只读集合权限。

该环境的云函数安全规则应保留原有 `*` 限制，并仅为本函数添加 `"webParentHomework": {"invoke": "auth != null"}`。这只放行已登录（含匿名登录）的调用；函数仍逐次核验每日反馈学生 ID 和手机号，不向浏览器开放 `hw_*` 集合读取。

此函数返回作业本截至查询时的累计完成量、整项完成状态，以及所选日期的计划和实际录入量。历史查询的累计完成量不是历史快照。没有实际记录时为 `null`，与已录入 `0` 区分；无计划也独立展示实际记录。

## 日期与独立加载

默认日期固定采用北京时间 YYYY-MM-DD，不依赖云端 ICU 区域格式。可传入 date 查询历史日期，必须为有效日期且不能晚于今天；历史查询还须处于 hw_settings/global 配置的学期范围。

列表只显示 assignmentDate 与查询日期一致的启用作业，以及查询日期存在计划或实际记录的启用作业。没有登记日期不代表每天重复展示。原始旧数据不补日期、不删除，本接口保持零写入。学生仍须通过既有显式关联核验；停用学生不展示作业。

家长页将作业与每日反馈、错题查询分开处理，某个模块失败不会隐藏成功读取的作业。网络或权限错误明确提示，不伪装成没有作业；允许选择日期和手动刷新。本地验证使用虚构数据，不能代替生产数据联调。
